  Generate OpenAPI 3.0 documentation for the selected API endpoint.

  Include:
  - Summary and description
  - Path parameters
  - Query parameters
  - Request body schema
  - Response schemas (all status codes)
  - Authentication requirements
  - Example requests/responses
  - Error codes
