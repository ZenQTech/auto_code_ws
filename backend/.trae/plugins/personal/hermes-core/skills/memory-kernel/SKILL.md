# Memory Kernel

Hermes 记忆内核技能，负责管理双轨持久记忆。

## 核心能力

1. **事件流记录**：每次交互自动记录到 `data/knowledge_base/memory/events.jsonl`
2. **语义图谱**：从事件中提取实体和关系，构建语义网络
3. **上下文召回**：根据当前任务从记忆库中检索相关上下文
4. **自我改进**：根据反馈自动调整记忆策略

## 使用场景

- 跨会话上下文延续
- 用户偏好学习
- 项目知识积累

## 输入

- 当前对话上下文
- 任务描述

## 输出

- 相关历史记忆片段
- 实体关系图
- 上下文摘要
