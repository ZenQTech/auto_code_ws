# 架构设计文档 (spec.md)

## 1. 模块视图
系统采用分层架构，共分为以下六大模块，职责清晰，依赖明确。

```
┌─────────────────────────────────────────────────────┐
│                   表现层 (Presentation)              │
│  ┌───────────────┐  ┌──────────────────────────────┐│
│  │  Web 管理界面  │  │  RESTful API (FastAPI)        ││
│  │  (React)       │  │  (任务提交、状态查询、管理等)  ││
│  └───────┬───────┘  └──────────────┬───────────────┘│
└──────────┼──────────────────────────┼────────────────┘
           │ HTTP/WebSocket           │ HTTP/JSON
           v                          v
┌─────────────────────────────────────────────────────┐
│                   调度层 (Scheduling)                │
│  ┌───────────────────────────────────────────────┐  │
│  │ 任务管理与调度器                                │  │
│  │ - 最少负载调度算法                             │  │
│  │ - 拓扑排序循环依赖检测                         │  │
│  │ - 任务状态跟踪                                 │  │
│  └───────────────┬───────────────────────────────┘  │
│                  │ 内部调用                            │
│                  v                                   │
│  ┌───────────────────────────────────────────────┐  │
│  │ 交通管理器 (Traffic Manager)                   │  │
│  │ - 路口协商                                     │  │
│  │ - 防碰撞机制 (距离阈值 0.3m/0.1m)               │  │
│  │ - 死锁检测与解除                               │  │
│  └───────────────┬───────────────────────────────┘  │
└──────────────────┼──────────────────────────────────┘
                   │ 内部调用
                   v
┌─────────────────────────────────────────────────────┐
│                   算法层 (Algorithm)                 │
│  ┌───────────────────────────────────────────────┐  │
│  │ 路径规划器 (Path Planner)                      │  │
│  │ - 三级执行策略路由算法                          │  │
│  │   - 第一级: A* (全局)                          │  │
│  │   - 第二级: Dijkstra (局部重规划)               │  │
│  │   - 第三级: 避障与微调 (传感器数据)              │  │
│  └───────────────┬───────────────────────────────┘  │
└──────────────────┼──────────────────────────────────┘
                   │ 下层调用
                   v
┌─────────────────────────────────────────────────────┐
│                   通信层 (Communication)             │
│  ┌───────────────────────────────────────────────┐  │
│  │ ROS 2 (或 ROS 1 Noetic) 适配器                 │  │
│  │ - Topic/Service 通信                          │  │
│  │ - AGV 心跳接收 (≥10Hz)                         │  │
│  │ - 指令下发 (速度、路径、急停)                   │  │
│  │ - 通信故障检测 (500ms超时)                      │  │
│  └───────────────┬───────────────────────────────┘  │
└──────────────────┼──────────────────────────────────┘
                   │ ROS 2 Topic/Service
                   v
┌─────────────────────────────────────────────────────┐
│                   数据层 (Data)                      │
│  ┌───────────────┐  ┌────────────────────────────┐  │
│  │ SQLite 数据库  │  │ 配置文件 (YAML)             │  │
│  │ (任务、AGV状态、│  │ (算法阈值、安全参数等)      │  │
│  │  日志、备份)    │  │                            │  │
│  └───────────────┘  └────────────────────────────┘  │
└─────────────────────────────────────────────────────┘
│ 监控与日志 (Monitoring & Logging)
│ ┌─────────────────────────────────────────────────┐  │
│ │ 统一的日志记录器 (Logging)                       │  │
│ │ 子进程管理器 (Subprocess Manager)               │  │
│ │ 环境依赖检查器 (Environment Checker)              │  │
│ │ 安全工具链检查器 (Security Toolchain Checker)     │  │
└─────────────────────────────────────────────────────┘
```
