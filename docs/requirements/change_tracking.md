**变更类型说明**:
- `新增` — 添加新功能需求或非功能需求
- `修改` — 修改已有需求的描述、指标或范围
- `删除` — 删除已有需求
- `确认` — 不确定项（U-n）经确认后转为确定需求
- `澄清` — 对已有需求的说明性补充，不改变实质内容

## 跟踪模板（每次变更使用以下格式）

```
### 变更编号: CR-xxx（自动递增）

| 字段 | 内容 |
|------|------|
| 日期 | YYYY-MM-DD |
| 变更人 | 角色/姓名 |
| 变更类型 | 新增 / 修改 / 删除 / 确认 / 澄清 |
| 涉及需求编号 | F-n / AC-n / U-n / 非功能 / 约束 / 安全红线 |
| 变更前内容 | （原始内容引用或描述） |
| 变更后内容 | （变更后内容引用或描述） |
| 变更原因 | （为何需要变更） |
| 影响范围 | （影响的模块、接口、测试等） |
| 风险等级 | 低 / 中 / 高 |
| 是否需要版本号递增 | 是 / 否 |
| 对应 CHANGELOG 链接 | CHANGELOG.md 对应条目 |
| 确认状态 | 待评审 / 已确认 / 已关闭 |
```
