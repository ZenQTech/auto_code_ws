> **文档版本**: v1.0
> **创建日期**: 2026-07-02
> **状态**: 已确认基线
> **基线类型**: 初始需求基线
> **上一版本**: 无（初始基线）

---

## 1. 项目概述

基于 ROS2 Humble 的 3-5 台 AGV 仓储调度系统，实现分布式拍卖任务调度、多传感器融合定位、自主导航与避障、Web 可视化监控及 REST API 对接。

- **运行平台**: Ubuntu 22.04 + ROS2 Humble
- **仿真环境**: Gazebo（Ubuntu 22.04）
- **通信网络**: WiFi 6 + DDS FastRTPS
- **AGV 数量**: 3-5 台
- **仓库面积**: 约 500 ㎡ 不规则仓库

---

## 2. 功能需求（10 个模块）

### F-1: 分布式拍卖任务调度
- 基于分布式拍卖算法的任务分配机制
- AGV 自主投标、竞标、任务认领
- 任务优先级管理与队列调度
- 多 AGV 任务负载均衡

### F-2: A* 全局路径规划
- 基于 A* 算法的全局路径搜索
- 静态障碍物地图的路径规划
- 路径平滑与优化
- 多 AGV 路径协调

### F-3: DWA 局部避障
- 基于 DWA（Dynamic Window Approach）的局部动态避障
- 实时障碍物检测与规避
- 速度空间搜索与轨迹评价
- 动态障碍物适应性

### F-4: EKF 多传感器融合定位
- 扩展卡尔曼滤波（EKF）融合以下传感器：
  - 轮式里程计（Wheel Odometry）
  - IMU（惯性测量单元）
  - LiDAR（激光雷达）
- 输出高频率、高精度位姿估计

### F-5: AMCL + Cartographer SLAM 自适应定位
- Cartographer SLAM 实时建图
- AMCL（自适应蒙特卡洛定位）提供全局定位
- 自适应模式切换：建图模式 ↔ 定位模式
- 地图加载与动态更新

### F-6: 双路急停 + 双重碰撞检测安全系统
- **双路急停**：硬件急停通道 + 软件急停通道，互为冗余
- **双重碰撞检测**：
  - 前向碰撞检测（基于 LiDAR）
  - 后向/侧向碰撞检测（基于安全传感器）
- 三层速度限幅机制

### F-7: Web 可视化
- 实时仓库地图显示
- AGV 位置实时跟踪
- 任务状态可视化
- 电量监控与告警
- Web 前端仪表盘

### F-8: REST API
- 任务下发接口
- 状态查询接口
- 系统配置接口
- 告警推送接口
- 标准 RESTful 设计，JSON 格式

### F-9: 故障恢复
- 故障检测与诊断
- 任务回滚机制
- 重新竞标流程
- 安全停车并返回充电桩
- 故障日志记录

### F-10: ROS2 DDS FastRTPS over WiFi 6 通信
- 基于 DDS FastRTPS 的通信中间件
- WiFi 6 网络适配与优化
- QoS 策略配置（RELIABLE 模式）
- 心跳检测（50ms 间隔）
- 断连检测与安全停车（200ms 超时触发）

## 6. 安全红线

### 6.1 双路急停
- **硬件急停通道**: 物理按钮直连电机电源切断，不经过软件逻辑
- **软件急停通道**: ROS2 安全节点检测异常后下发停机指令
- 两通道互为冗余，任一触发即执行安全停车

### 6.2 双重碰撞检测
- **前向检测**: 基于 LiDAR 的前方障碍物检测
- **后向/侧向检测**: 基于安全传感器或 LiDAR 点云的多方向检测
- 检测到碰撞风险时触发减速或急停

### 6.3 三层速度限幅
- **第 1 层 - 硬件层**: 电机驱动器固件级硬限幅（不可软件修改）
- **第 2 层 - 固件层**: 嵌入式控制器指令限幅
- **第 3 层 - 软件层**: ROS2 控制节点速度指令限幅

### 6.4 通信故障安全
- 心跳 50ms，断连 200ms 触发安全停车
- 通信恢复后自动尝试重连

### 6.5 故障恢复链路
- 故障检测 → 任务回滚 → 重新竞标 → 安全停车 → 返回充电桩
- 全链路自动化，故障接管 ≤ 500ms
